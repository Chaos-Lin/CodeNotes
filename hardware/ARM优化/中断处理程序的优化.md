# 中断处理程序的优化

为了平衡中断处理程序时间要求短和工作量要大的问题，Linux将中断处理程序分为**顶半部(top half)**和**底半部(bottom half)**。

顶半部负责处理紧急的事情，不紧急的事情放在底半部。

顶半部往往不可被中断，底半部往往可以被中断。

顶半部完成的一般是紧急的硬件操作，一般包括读取寄存的中断状态，清除中断标志，将底半部处理程序挂到底半部的执行队列中去。这样，顶半部执行的速度就会很快，可以服务更多的中断请求。

底半部用来完成中断事件的绝大多数任务，执行大部分的耗时操作。

顶半部和底半部中断操作的划分经验：

如果一个任务对时间十分敏感，将其放在顶半部。

如果一个任务和硬件有关，将其放在顶半部。

如果一个任务要保证不被其他中断打断，将其放在顶半部。

其他所有任务，考虑放在底半部。

实现底半部中断的三种机制：

1.软中断（softirq）

2.tasklet

3.工作队列（workqueue）

## 软中断（softirq）

软中断是一个内核子系统，每个 CPU 上会初始化一个 `ksoftirqd` 内核线程，负责处理各种类型的 softirq 中断事件。

softirq有如下特点：

- softirq 是在 Linux 内核编译时就确定好的，例外网络收包对应的 `NET_RX_SOFTIRQ` 软中断。因此是一种**静态机制**。如果想加一种新 softirq 类型，就需要修改并重新编译内核；
- 同一个softirq支持在不同的 cpu 上并发执行，因此执行效率比较高；
- softirq可以被顶半部中断打断，但不会被softirq打断；
- 顶半部中断优先级>softirq优先级>普通进程；
- 通常情况下，softirq在顶半部中断结束会会被执行，运行在软中断上下文中；特殊情况下（当系统频繁进行顶半部中断和软中断的切换，导致普通进程无法被调度时），部分软中断会被移交到内核线程中执行，将其调度优先级降低。在这种情况下，软中断运行在进程上下文中。



## tasklet

tasklet是一种特殊的软中断。

tasklet特点：

- 用户可以将需要处理的底半部任务注册到内核的tasklet中；
- 可以动态增加减少，没有数量限制；
- tasklet运行在软中断上下文；

- 同一段tasklet代码在某个时刻只能在一个CPU上运行；
- 不同的tasklet代码在同一时刻可以在多个CPU上并发地执行；



## 工作队列（**workqueue** ）

特点：

- Workqueue在进程上下文中执行，可以执行阻塞函数，工作执行过程中可以被重新调度、抢占、睡眠；

- 可以在多个CPU内核上并发执行，内核会自动调度工作队列中的任务；

- 允许开发者创建和管理自己的工作队列；

- 高优先级的队列优先执行，队列内部按照FIFO顺序执行。

## FreeRTOS 

FreeRTOS支持延迟中断处理技术，类似于Linux中的顶半部和底半部处理。

FreeRTOS支持两种方式进行中断延迟处理：

- 集中式延迟中断处理：
  - 每个中断都是在同一个 RTOS 守护进程任务的上下文中执行，它们会以相同的 RTOS 任务优先级执行 ；
  - RTOS 守护进程任务按照FIFO顺序进行处理；
  - 写入定时器命令队列，然后再从该队列中读取， 会增加一个额外的延迟；

- 应用程序控制延迟中断处理：
  - 每个中断都是在应用程序写入器创建的任务的上下文中执行；
  - 可使延迟中断任务的相对优先级 与它们各自中断的相对优先级相匹配；
  - 减少了延迟（函数指针不通过队列传递）；
### µC/OS-III

在 version 3.03.00（2016 06 30）之前支持Deferred Interrupt Processing，此后废除。

处理完ISR后将延迟发布（执行）函数调用和相应的参数写入到专用队列中，该队列称为中断队列。然后使中断队列处理任务进入就绪态，这个任务是UCOSIII的内部任务，并且具有最高优先级0。

### 在无OS单片机上实现中断延时处理

#### 在进程上下文

考虑在主循环中加入控制标志flag及相应的处理函数，中断到来后，在ISR中修改标志，推出ISR后，在主函数中执行对应的函数。进一步的，可以设置执行队列，退出ISR后依次执行所有的中断延时处理任务。

特点：

- 进程上下文中执行，可以执行阻塞函数，工作执行过程中可以被抢占、睡眠；
- 可以被中断抢占，不可以抢占普通程序，无法被普通程序抢占；

#### 在中断上下文

类似于在进程上下文，但是需要执行的任务不再主函数中，而是建立一个优先级最低的中断，在该中断中执行。

特点：

- 中断上下文中执行，不可以执行阻塞函数，工作执行过程中不可以睡眠；
- 可以被高级中断抢占，可以抢占普通程序，无法被普通程序抢占；
