
# Spring

## resource&autowired
`@Resource`：它属于 JSR-250 规范，是 JavaEE（现 Jakarta EE）的标准注解。这意味着使用 @Resource 注解编写的代码具有更好的跨框架移植性，若之后要从 Spring 框架迁移到其他支持 JSR-250 规范的框架，该注解依然能正常使用。
`@Autowired`：是 Spring 框架自身提供的注解，只能在 Spring 框架中使用。
```java
@Resource(name = "blogService")
private IBlogService blogService;
```
```java
@Autowired
@Qualifier("blogService")
private IBlogService blogService;
```
